# Código de Conducta

Este proyecto adopta el [Contributor Covenant, versión 2.1](https://www.contributor-covenant.org/es/version/2/1/code_of_conduct/).

## Nuestro compromiso

Queremos que participar en este proyecto sea una experiencia libre de acoso para todas las personas, sin importar edad, tamaño corporal, discapacidad, etnia, identidad o expresión de género, nivel de experiencia, educación, nivel socioeconómico, nacionalidad, apariencia, raza, religión u orientación sexual.

## Comportamiento esperado

- Ser respetuoso y amable, también en las discusiones técnicas y sobre estrategias.
- Aceptar críticas constructivas y darlas de forma constructiva.
- Enfocarse en lo mejor para la comunidad.

## Comportamiento inaceptable

- Insultos, comentarios despectivos o ataques personales.
- Acoso público o privado.
- Publicar información privada de otras personas sin permiso.
- Cualquier conducta inapropiada en un entorno profesional.

## Aplicación

Los mantenedores pueden editar o eliminar comentarios, commits, issues y estrategias que no respeten este código, y bloquear temporal o permanentemente a quien lo incumpla.

Para reportar un problema, contactá a los mantenedores en privado: por mensaje privado en GitHub o con el reporte privado del repositorio. Todos los reportes se tratan con confidencialidad.
